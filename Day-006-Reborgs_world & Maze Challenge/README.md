# Day 6 - Reborg's World Maze Challenge

## What I Learned
- Functions for reusable, structured code
- While loops to navigate until reaching the finish line
- Organizing logic into readable code blocks

## Project Overview
Guide Reborg, a robot starting at a random position and direction, through a maze to the finish line using logical instructions.

## Code Highlights
- While loops driving movement until the finish condition
- Functions breaking movement into structured steps
- Same code solved both Hurdle 3 and Hurdle 4 with no modifications
