# Day 9 - Blind Auction Project

## What I Learned
- Dictionaries for storing data as key-value pairs
- Nested lists — lists inside lists, accessed by index
- Nested dictionaries for representing more complex, structured data

## Project Overview
Console-based blind auction where participants place anonymous bids, and the highest bidder wins.

## How It Works
- Displays an ASCII logo on start.
- Prompts each bidder for name and bid amount, stored in a dictionary; clears the screen between bidders.
- Once all bids are in, compares them and announces the winner.

## Code Highlights
- Dictionary storing names as keys, bids as values
- For loop comparing all bids to find the highest
- Final output showing winner's name and bid
