# Day 5 - Password Generator

## What I Learned
- For loops to repeat actions efficiently
- `range()` to generate number sequences
- Organizing code into clear blocks

## Project Overview
Generates two types of passwords from user-specified counts of letters, numbers, and symbols:
- **Strong Password:** fully randomized (shuffled) mix of characters
- **Sequence Password:** letters first, then numbers, then symbols

## Code Highlights
- `random.choice()` to pick random characters
- `random.shuffle()` to randomize order for the strong version
- For loops to automate password building
